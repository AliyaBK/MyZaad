# Zaaduna

**→ [aliyabk.github.io/Zaaduna](https://aliyabk.github.io/Zaaduna/)**

Платформа, где собраны вопросы по циклам лекций крупных учёных в переводе
и изложении устазов. Прослушанная лекция превращается в пройденную главу:
читатель идёт по экранам, проверяет себя и уносит конспект — а с ним список
дел, которые решил начать.

Приложение рассчитано на того, кто лекцию **уже** прослушал. Оно не заменяет
урок и не пересказывает его.

## Источник

Глава 1 — цикл «Ща'бан», устаз Ибрахим Братов, по пятничным проповедям шейха
Мухаммада ад-Дубейси. Аудио: канал [«Радость благочестивых»](https://t.me/Mesiac_Shaaban_Ramadan).

Вопросы и варианты ответов, включая правильные, утверждает преподаватель
того цикла, к которому они относятся.

## Как это сделано

Статический сайт без сборки и зависимостей: откройте `index.html` в браузере
или положите папку на любой хостинг.

| Файл | Что делает |
|---|---|
| `index.html` | оглавление: правила и выбор цикла |
| `chapter.html` | экран главы, параметр `?ch=N` выбирает главу |
| `konspekt.html` | печатный лист главы, он же PDF через печать |
| `engine.js` | движок: типы экранов, проверка, прогресс, выгрузки |
| `konspekt.js` | сборка печатного листа из данных главы |
| `journey.js` | путь цикла: лодка на линии от первого урока к последнему |
| `theme.js` | выбор между ночью и днём, память о нём |
| `cursor-dhow*.png` | курсор: знак платформы, покой и наведение, светлая и тёмная |
| `tools/render-cursor.py` | пересобрать курсор из `assets/logo-mark.png` |
| `chapter1-data.js` | **единственный файл, который пишут для новой главы** |

Движок понимает восемь типов экранов: `content`, `single-choice`,
`true-false`, `ordering`, `fill-blank`, `multi-select`, `reveal`, `result`.
Прогресс и ответы хранятся в `localStorage` того браузера, где открыта глава.

### Добавить главу

Создайте `chapter2-data.js` по образцу первого и откройте `chapter.html?ch=2`.
Движок, стили и конспект править не нужно — лист соберётся сам.
